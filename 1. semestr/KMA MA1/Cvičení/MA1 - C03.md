# Příklad 1. 
Vypočtěte limitu

1 ${}\lim_{ n \to \infty } \frac{5n^{2}+2}{n^{3}+6}=0{}$

2 ${}\lim_{ n \to \infty } \frac{1-n^4}{1+n^{3}+3n^4}=-\frac{1}{3}{}$

3 ${}\lim_{ n \to \infty } \left( \frac{n^{2}}{n+1}-\frac{n^{2}+3n}{n+2} \right)=\lim_{ n \to \infty } \frac{n^{3}+2n^{2}-n^{3}-3n^{2}-n^{2}-3n}{n^{2}+2n+n+3}=\lim_{ n \to \infty } \frac{-2n^{2}-3n}{n^{2}+3n+3}=-2{}$ 

4 ${}\lim_{ n \to \infty } \frac{\sqrt{ n^5+n }}{n^{2}+1}= \lim_{ n \to \infty } \frac{n^{1/2}\sqrt{ 1+\frac{1}{n^4} }}{1+\frac{1}{n^{2}}}=\infty{}$

5 ${}\lim_{ n \to \infty } \frac{n^\alpha-7}{n^{3}+2n},\alpha \in \mathbb{R}=\begin{cases}\infty & \alpha>3 \\  1 & \alpha=3 \\  0 & \alpha<3\end{cases}{}$

6 ${}\lim_{ n \to \infty } \frac{n^\alpha+3n}{2n-1},\alpha \in \mathbb{R}=\begin{cases}\infty & \alpha>1 \\  2 & \alpha=1 \\  1.5 & \alpha<1\end{cases}{}$

7 ${}\lim_{ n \to \infty } \frac{n+(-1)^nn^{2}}{2n^{2}+3}=\nexists{}$

8 ${}\lim_{ n \to \infty } \frac{3^n+5}{2^n+3^n}=\lim_{ n \to \infty } \frac{1+\frac{5}{3^n}}{\left( \frac{2}{3} \right)^n+1}=1{}$

9 ${}\lim_{ n \to \infty } \frac{2^n+5^{n+2}}{\alpha^n+1},\alpha>0=\begin{cases}0 & \alpha>5 \\  25 & \alpha=5 \\  \infty & \alpha<5\end{cases}{}$

4 ${}\lim_{ n \to \infty } \frac{\sqrt[n]{ n^n+1 }}{n+1}=\lim_{ n \to \infty } \frac{n\sqrt[n]{ 1+\frac{1}{n^n} }}{n\left( 1+\frac{1}{n} \right)}=1{}$
