> **Téma:** **Vlastnosti limit funkcí.** Limita složené funkce.
> **Koncepty:** [[Posloupnost]]

**Příklad**: (neurčité výrazy)
1) Ad "${}\frac{\infty}{\infty}{}$":
		
	$$
	\begin{align}
	\lim_{ n \to \infty } \frac{n}{n^{2}}=| \frac{\infty}{\infty}|=\lim_{ n \to \infty } \frac{1}{n}=0 \\
	\lim_{ n \to \infty } \frac{n^{2}}{n}=| \frac{\infty}{\infty}|=\lim_{ n \to \infty } n=+\infty \\
	\lim_{ n \to \infty } \frac{3n}{2n}=| \frac{\infty}{\infty}|=\lim_{ n \to \infty } \frac{3}{2}=\frac{3}{2}
	\end{align}
	$$
1) Ad "${}\infty-\infty{}$":
		
	$$
	\begin{align}
	\lim_{ n \to \infty } (2^n-3^n)=\lim_{ n \to \infty } 3^n\cdot\left( \left( \frac{2}{3} \right)^n-1 \right)=-\infty \\
	\lim_{ n \to \infty } (3^n-2^n)=\lim_{ n \to \infty } 2^n\cdot\left( \left( \frac{3}{2} \right)^n-1 \right)=+\infty \\
	\lim_{ n \to \infty } (\sqrt{ n+1 }-\sqrt{ n })\cdot \frac{\sqrt{ n+1 }+\sqrt{ n }}{\sqrt{ n+1 }+\sqrt{ n }}=\lim_{ n \to \infty } \frac{1}{\sqrt{ n+1 }+\sqrt{ n }}=0
	\end{align}
	$$

**Poznámka** (asymptotické nerovnosti)
	Zápis ${}a_{n}\ll b_{n}{}$ pro ${}n\to \infty{}$ znamená, že:
	1) ${}a_{n},b_{n}\to +\infty{}$
	2) ${}\frac{a_{n}}{b_{n}}\to 0{}$
	Platí:
$$
\boxed{\log_{a}n\ll n^k\ll a^n\ll n! \ll n^n \text{ pro } n\to \infty}
$$
	Pozn.:  ${}a_n\ll b_{n}{}$ pro ${}n\to \infty{}$      ${}\dfrac{b_{n}}{a_{n}}=\dfrac{1}{\frac{a_{n}}{b_{n}}}\to+\infty{}$

Dk.:
1) ${}\frac{n!}{n^n}\to 0{}$ pro ${}n\to \infty{}$
	${}0<\frac{n!}{n^n}=\frac{n\cdot(n-1)(n-2)\dots 3\cdot 2\cdot 1}{n\cdot n\cdot n\dots n\cdot n\cdot n}<\frac{1}{n}{}$
	věta o sevření ${}\implies \frac{n!}{n^n}\to 0{}$

2) pro ${}a=e{}$:    ${}\frac{e^n}{n!}\to 0{}$ pro ${}n \to \infty{}$        
	${}0< \dfrac{e^n}{n!}= \dfrac{e\cdot e\cdot e\cdot \dots \cdot e\cdot e\cdot e}{n\cdot(n-1)(n-2)\dots 3\cdot 2\cdot 1}< \frac{e}{n}\cdot \frac{e}{2}\cdot \frac{e}{1}\to 0{}$
	${}\frac{e}{n}\to 0{}$         ${}\frac{e}{2}\cdot \frac{e}{1}{}$ je číslo
	věta o sevření ${}\implies \frac{e^n}{n!}\to 0{}$

 3) ${}\frac{n}{e^n}\overset{?}{\to} 0{}$         ${}b_{n}=\frac{n}{e^n}{}$
	 $${}\frac{b_{n+1}}{b_{n}}= \frac{\frac{n+1}{e^{n+1}}}{\frac{n}{e^n}}=\frac{n+1}{\cancel{e^n}\cdot n}\cdot \frac{\cancel{e^n}}{n}=\frac{n+1}{n}\cdot \frac{1}{e}\leq \frac{2}{e}{}$$

4) ${}\frac{\ln n}{n} \overset{?}{\to}0{}$
	${}\ln n=r{}$    ${}n=e^r{}$       ${}[r]=m{}$     pro ${}n\to \infty\implies m\to \infty{}$
	$${}0\leq \frac{\ln n}{n}=\frac{r}{e^r}\leq \frac{[r]+1}{e^{[r]}}= \frac{m+1}{e^m}=\frac{m}{e^m}+\frac{1}{e^m}\to 0{}$$
	${}\dfrac{m}{e^m}\to 0{}$      ${}\dfrac{1}{e^m}\to 0{}$


**Příklad**: (důležitý)
1) ${}\lim_{ n \to \infty }\sqrt[n]{ n }=1{}$
	${}\forall a>1: \frac{n}{a^n}\to 0{}$      (${}n\ll a^n{}$ pro ${}a>1{}$)     
	${}\forall h>0: \frac{n}{(1+n)^n}\to 0{}$    (${}a=1+h,h>0{}$)
	  ${}\frac{n}{(1+h)^n}<1{}$ p.s.v. ${}n\in \mathbb{N}{}$
	${}\implies 1\leq n<(1+n)^n{}$ p.s.v. ${}n\in \mathbb{N}{}$   /${}\sqrt[n]{  }{}$
	${}1-h<1\leq \sqrt[n]{ n }<1+h{}$
	${}\forall h>0:1-h<\sqrt[n]{ n }<1+h{}$ p.s.v. ${}n\in \mathbb{N}{}$
	${}\forall \epsilon>0:1-\epsilon<\sqrt[n]{ n }<1+\epsilon{}$ p.s.v. ${}n\in \mathbb{N}{}$

2)  ${}\lim_{ n \to \infty }\sqrt[n]{ a }=1{}$ pro ${}a>0{}$
	pro ${}a>1:{}$     ${}1<a<n{}$     p.s.v. ${}n\in \mathbb{N}{}$ /${}\sqrt[n]{ n }{}$
	    ${}1<\sqrt[n]{ a }<\sqrt[n]{ n }\to 1{}$
	pro ${}a\in(0,1){}$:
	    ${}\lim_{ n \to \infty }\sqrt[n]{ a }=\lim_{ n \to \infty } \dfrac{1}{\sqrt[n]{ \frac{1}{a} }}=1{}$

# Kritéria konvergence
> [!question]
> Jak ověřit, že (${}a_{n}{}$) je konvergentní v případě, že neumíme určit limitu ${}a\in \mathbb{R}{}$?

> [!quote] Věta (konvergence monotóní posloupnosti)
>   $$
\left.
\begin{align}
\text{Pokud } (a_{n}) \text{ je monotóní posloupnost} \\
\text{a } (a_{n}) \text{ je omezená posloupnost}
\end{align}\right \}\implies \exists \lim_{ n \to \infty }a_{n}= \begin{cases}
\mathrm{sup}(a_{n})\text{ pro }(a_{n}) \text{ rostoucí}  \\
 \mathrm{inf}(a_{n})\text{ pro }(a_{n}) \text{ klesající}
\end{cases}
$$

**Dk.:**

$$ (a_n) \text{ je neklesající} \stackrel{\text{def}}{\iff} \forall n \in \mathbb{N}: a_n \le a_{n+1} $$

$$ (a_n) \text{ je omezená} $$

$$ \implies (a_n) \text{ je omezená shora} \implies \exists! \sup(a_n) = \beta $$

$$ \stackrel{\text{def}}{\implies} \forall \varepsilon > 0 \ \exists n_0 \in \mathbb{N}: \beta - \varepsilon < a_{n_0} $$

$$ \forall n \in \mathbb{N}: n > n_0 \implies a_{n_0} \underset{\text{mon.}}{\le} a_n $$

---

$$ \forall \varepsilon > 0 \ \exists n_0 \in \mathbb{N} \ \forall n \in \mathbb{N}: n > n_0 \implies $$

$$ \boxed{\beta - \varepsilon < a_{n_0} \le a_n \underset{(*)}{\le} \beta < \beta + \varepsilon} $$


> [!note] Definice (Eulerovo číslo)
> 
> $$
> e:=\lim_{ n \to \infty } \left( 1+\frac{1}{n} \right)^n
> $$

${}\left( 1+\frac{1}{n} \right)^n{}$ konverguje ?
1) ${}\left( 1+\frac{1}{n} \right)^n{}$ je omezená
2) rostoucí
	${}\implies{}$ konvergentní

Platí:
$$
\lim_{ n \to \infty } \left( 1-\frac{1}{n} \right)^n=\frac{1}{e}
$$

> [!note] (Cauchyovksá posloupnost)
> Řekneme, že ${}(a_{n}){}$ je **cauchyovská**, pokud
> $$
>\forall\epsilon>0\exists n_{0}\in \mathbb{N}\forall m,n\in \mathbb{N}: \left . \begin{align}
>m>n_{0} \\
>n>n_{0}
>\end{align} \right \} \implies |a_{m}-a_{n}| <\epsilon
> $$
